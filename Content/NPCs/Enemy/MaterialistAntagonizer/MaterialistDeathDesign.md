# 物欲拮抗者：死亡演出

以当前仓库“进化的本质”的死亡演出为时序参考，转换成机械舰体过载、光子切割与电子解体。只改变死亡表现，不增加死亡战斗阶段。

## 同步的时长与力度

| 项目 | 规则 |
|---|---|
| 本体死亡过程 | 200游戏帧，沿用EvolutionPresentationRules.DeathDuration |
| 总爆发 | 第180帧，沿用EvolutionPresentationRules.DeathFinale |
| 总爆发余波 | 96帧，世界视觉截止第276帧 |
| 镜头 | 24帧平滑移入，余波后36帧移回玩家实时视角；不存旧玩家坐标 |
| 连锁电爆节奏 | 前120帧每5帧一轮，随后每2帧一轮；90帧后每轮2处、156帧后3处，与进化的本质共用节奏函数 |
| 装饰方粒子 | 普通256个环绕数据包，精简32个；碎片池1152／精简224，与参考演出同级预算 |
| 震动 | 镜头持续震动从1渐升至5，第180帧强度9后按余波衰减；局部电爆脉冲强度3、总爆发9，衰减0.84，沿用参考的2.43／1.83振动频率与距离衰减 |

屏幕震动、精简特效沿用物欲拮抗者设置，并新增默认开启的死亡镜头设置。精简模式减少激光／光刃／碎片、停用震动，保留完整时序与回镜头。演出不锁玩家操作，不改玩家世界位置。

## 四段演出

### 0～48帧：指挥链故障

镜头移到母舰。原有锁血全息护盾按既有速度卸下；引擎保留喷焰，并逐步失压熄灭。机身轻颤、青色扫描框与数据网格开始错位，方形数据包向核心聚拢。局部电爆从机壳不同位置连续亮起，带白色亮芯与青／橙／紫外辉。

### 48～120帧：激光泄漏与光子切割

多个位置依次向外伸出无伤激光，每14帧新增一组；每组先形成起点，再用12帧展开长度，随后短暂停留并在末段收束消失。使用原版分段激光纹理与本Boss的亮度重着色，包含起点、动画主体、末端、彩色外辉与白芯。

第72帧起，不同角度的光刃轮流横切舰体。独立MaterialistSeverance材质绘制弯曲渐尖亮刃与破碎方粒子外鞘，不创建剑气攻击。正负方向交错穿行，电爆、断续发射声和低频过载声逐渐叠合。

### 120～180帧：全舰解体

电爆提高到每2帧一轮。激光组从2条提升至3条，末段提升至5条；光刃继续交错。原始母舰贴图按12条机壳层逐渐错开并抛离，机体专用MaterialistDisassembly材质按方形单元失效，带扫描断层、青橙色分离与亮边。

机壳真实贴图片段、独立亮芯方粒子及短能量拖尾向外扩散。机身只在死亡期间解体；战斗中的贴图和威龙表现不受影响。不加回此前删除的炮口圆环。

### 180～276帧：核心崩溃与余波

第180帧核心总爆发，释放220个终结碎片及多层方形冲击边界、短光束残迹与局部水平强光。第200帧本体完成既有死亡／掉落／击败记录流程；客户端保留终结快照，余波不会因NPC删除而突然消失。

原有激光按各自生命继续淡出，方形冲击边界向外推进，机壳碎片继续翻转落下，亮粒子逐渐减速熄灭。第276帧视觉余波结束，再用36帧平滑回到玩家当前位置。

## 无伤与联机边界

- 全部演出光束、斩击、局部电爆、碎片和方粒子都只存在于本地视觉池／绘制函数，没有NPC、Projectile、碰撞、伤害或地形破坏。
- 母舰仍全程无接触伤害；死亡时既有清弹逻辑立即让战斗弹幕无伤，护航机按既有规则退出。
- 此前单独设计的威龙阵亡粘性炸弹仍按自己的引信与伤害规则工作；它不是本次母舰演出的粒子或假攻击。
- 仅权威端完成200帧死亡判定，并每30帧同步死亡进度；客户端跟随本场Encounter与Timer。只追踪2800像素内开始的演出，进入后可完整看完；晚加入从当前进度显示，重复网络快照不会重放旧音效与粒子爆发。
- 断线／退回菜单／切换世界清空本地演出；本地玩家死亡时取消镜头跟随。事件最多补发最近4帧，防止网络跳帧触发积压爆发。
- 参考Evolution现有镜头播放结构及规则常量，不修改Evolution源码。游戏内视觉、声音混合、联机与低配表现仍待验收。
