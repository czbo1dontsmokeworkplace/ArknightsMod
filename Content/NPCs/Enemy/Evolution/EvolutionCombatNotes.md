# 进化的本质：女皇式弹幕调校、穿场冲刺与十六秒三叉光轴（2026-09-26）

仅借鉴攻击组织方式；本次没有复制 Infernum 的贴图或 shader，也未增加 Luminance 依赖。旧地面敌人贴图完整保留，但所有现役仆从改为红色光球绘制。

## 本次难度调校

- 常规弹幕数量不变：激光墙仍28束、血喷梳阵仍26枚、完美形态常规招式仍六轮。光轴侧射按最新要求提频并延长招式，见下方。原有实体数量上限保留。
- 每招开始锁定一次阵型中心与横向行进方向；中后期通道以每帧1.6～3像素缓慢平移，偏向玩家起手时的移动方向，不会跟着玩家每次躲闪重新定位。初生形态和第一次转场不漂移。
- 大多数血灵按阵列飞行，不再整团追着玩家收拢；只有育生核心分裂的少量血灵保留轻追踪，最多修正24帧，靠近玩家420像素内永久锁定方向，不再擦身掉头。
- 扇面不删除中央弹，而是把全部弹重新分布到通道两侧；墙、梳阵、支援血雨和地面波使用同一阵型基准。炸弹放到外围，碎片保持直线放射；滚石改为同向前后经过，避免两边同时夹击。
- 普通激光至少预警64帧后生效；完美形态齐射间隔由48/42帧变为53/47帧，仍完整播放六轮。普通直线血喷和碎片在原减速基础上再降速10%，招式间空档再放宽约10%。
- 所有普通伤害弹逐项乘以90%并向下取整，纯提示弹仍为0；本体和仆从碰撞伤害不变。唯一例外是终末血色光轴的基础伤害9999，其他激光与侧射刃都不会继承。
- 目标是更接近女皇的可读阵型，并照顾世纪之花时期的机动能力；“比炼狱女皇低约10%”是实战调校目标，不能通过参数表证明已经精确达成。

## 招式变化

- 第二轮弹幕炼狱：每三轮激光中的一轮为八向放射激光；阵型中心方向位于两束之间，不追瞄。不是额外堆在原激光墙上。其他炸弹、落石和地面喷柱保留。
- 中后期连射光球：使用原 Puppet 仆从逻辑槽位，一生只锁定一次发射方向，瞄向通道侧边；只沿这条直线缓慢前移，距离玩家420像素内停止。六连发、每18帧一发，然后休息；每发独立预警。单束点射伤害窗口6帧，视觉衰减12帧。二阶段对应协同激光招式，最终阶段对应纵向激光墙招式。
- 最终阶段血色光轴：先移到侧面蓄力，从本体向外伸出三条单向射线，彼此始终相隔120度；不是三条贯穿线，不存在背向的额外三束。实际攻击持续960帧（16秒，准备与退场另计）。准备及激光生效期间本体无敌，不能因伤害、死亡或8%转阶段提前跳过，最后8%转阶段等光轴结束再处理。本体停稳，不追着玩家拖动光柱。
- 转速：顺时针2秒从零平滑加速到最高0.00504弧度/帧（上一版0.00252的两倍），保持4秒，再用2秒减速到零；随后逆时针重复2秒加速、4秒匀速、2秒减速。两段各转约104度，最终回到起始角度；总时长、侧射频率和伤害不变，换向没有跳角或速度突变。
- 光轴侧刃：整组发射节拍从60帧一轮提高到40帧一轮，即频率1.5倍。每轮仍七对，在三条射线上轮流、由内向外释放；轮内间隔由7帧缩短到交替4～5帧，最后一对后留停顿。每轮轮换起始射线以均衡密度，不把三条射线同时三倍齐射。完整16秒安排23轮、共322枚侧刃，近本体两个槽保留；贴图方向及普通血喷伤害36不变。
- 发射音效：确认使用原版 `SoundID.Zombie104`，实际激光出现时整组只播放一次，反转时不重复播放。核对来源：本地原版 `Projectile.cs` 的455号弹幕首次启动调用 `PlaySound(29, ..., 104)`；`ProjectileID.PhantasmalDeathray = 455`、`SoundID.Zombie = 29`，`SoundID.TML.cs` 定义对应的 `Zombie104`。
- 光轴加宽：材质承载宽度150→450，碰撞线宽40→120；中心线与两侧边界一起预警。加强深红外焰、亮丝和白热核心，边缘保持柔和消隐，不用实体矩形填色。
- 中后期冲刺：保持三连冲刺和原有最高速度，从玩家左右约1120/1280像素处准备；中期冲刺持续52帧，最终冲刺44帧，穿过玩家后滑行至远端再准备下一次。保留后坐、渐进加速和双侧尾迹，不读取屏幕分辨率；不同缩放下是否完全出画不作硬性保证。
- 远端预瞄：本体启用屏外绘制，避免因为起点在画面外而连带剔除穿场预瞄线。
- 不加入旋转转子招式，也不移植绿色炸弹或邪教徒原有魔法团。

## 最终阶段顺序

20%～8%：光轴 → 冲刺 → 纵向激光墙/连射光球 → 交替激光墙/地面波 → 综合激光 → 激光/炸弹 → 冲刺 → 激光/血灵 → 综合激光，循环。

8%以下：冲刺 → 光轴 → 纵向激光墙/连射光球 → 综合激光，循环。普通招式在死亡、离场和8%模式切换时清场；光轴执行期间延期处理死亡与8%切换，但玩家全灭等正常离场逻辑仍然保留。

## 所有射线共用的预警顺序

预警线约前20帧平滑出现 → 保持到原预警时点 → 用16帧平滑消失 → 淡出第8帧（亮度50%）时真实激光瞬间出现 → 剩余预警继续淡出。

普通激光、短点射、光轴、尖刺射线、地面喷柱统一使用这个时钟。地面喷柱保留原有柱体长出后才伤人的6帧安全延迟。真实激光与伤害判定不会因独立视觉计时而脱节。

## 资源与伤害

- 新原创材质：`Assets/Effects/EvolutionHemalAxis.fx` 和编译结果 `.fxc`，由本模组 `Content/Projectiles/Medic/Shining/NoiseSoft.png` 驱动。双向流动噪声、交织亮丝、稳定白热核心；不是三段贴图。
- 光球：复用本模组柔光与环形纹理，以运行时红色染色叠绘；小光点数量和球体大小区分仆从职责。
- 能量刃：复用我们自己的灰度 `EvolutionLance` 资源，横向展开为刃形，仍属于血喷。
- 扩散激光、连射激光共用驾驶舱 Blood Laser（40）；侧射刃共用 Blood Lance（36）；终末光轴只通过特殊表 Final Hemal Axis（9999）读取伤害。
- 驾驶舱：`EvolutionDamageCockpit.cs`；阵型/节奏：`Evolution.PatternFairness.cs`、`EvolutionRules.cs`；光轴：`Evolution.HemalPatterns.cs`。所有数值为基础伤害，不保证难度倍率、防御和减伤后的最终扣血恰好等于表中整数。
