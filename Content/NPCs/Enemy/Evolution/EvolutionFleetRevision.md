## 黄阶段到红阶段

- 80%门槛进入原有600帧转场。现存小怪保留150帧退场时钟：前108帧逐渐蓄力和震动，随后黄色爆散、烟雾与淡出；无伤害、不产生分裂幼体。Molting与原有NPC时钟同步，迟加入者不会重新播放完整蓄力。
- 本体在140～390帧由黄色慢慢变红，390～590帧交叉显露进化形态；位置、绘制支点也逐渐从站立过渡到升空。
- 上下边界在390～510帧逐渐出现，510帧完全可见才开始限高；原黄色圆形边界先淡出。转场尾部激光实际开火晚于边界完全显现。

## 钢琴与舰炮式攻击

原先12秒的额外下砸开场缩短到552帧（9.2秒），仍不消耗80%～40%血量段。锁向42帧、84帧俯冲、108帧落地，48帧撤离窗口后释放第一轮扇光；第二轮、孵化与重力焰核随之提前。

普通轮回由六个乐句组成，每个乐句都在原有钢琴攻击之后穿插快速下砸、另一种弹幕、折线冲刺：

1. 和弦 → 快速下砸 → 左右舷扇射 → 折线冲刺。
2. 滑奏 → 快速下砸 → 留空航道弹墙 → 折线冲刺。
3. 琶音 → 快速下砸 → 错拍扩散 → 折线冲刺。
4. 颤音 → 快速下砸 → 纵向激光列 → 折线冲刺。
5. 断奏 → 快速下砸 → 双翼喷焰 → 折线冲刺。
6. 复奏 → 快速下砸 → 火箭及蜿蜒辐射流 → 折线冲刺。

钢琴和普通弹幕招式234帧；两种移动攻击216帧，恢复27帧。下砸与折线冲刺分别约每16.8秒回归一次，而不是只在开场使用一次。

- 快速下砸：24帧锁定、48帧起动、66帧落地、102帧释放扇光预警。没有开场裹挟玩家的机制，整招结束前保留激光尾光。
- 折线冲刺：每段68帧，共三段；每段锁向后20帧预警，再以44像素／帧冲刺22帧，上下斜向交替。每段三次向两侧甩弹，共18枚，有独立预警和有限寿命。
- 左右舷扇射：两侧轮替三组八发，扇心留空，方向在生成时固定。
- 航道弹墙：两侧交替四列，每列七枚、留下连续两行空位，空位只平移一行后回移，不突然封满飞行高度。
- 错拍扩散：三次带缺口的扩散，角度与初速轻微错开，无持续追踪。
- Barrage是独立的小型亮芯弹，伤害在统一驾驶舱中配置。实际碰撞是短线段，预警期静止无伤害；寿命末段淡出。
- 开场与重复下砸的扇光在上下边界仅折射一次，保留整条光路总射程。预警、材质绘制和碰撞共享同一条双线段路径；未到边界的浅角射线不会凭空折射，也不会继续递归折射。

## 小怪数量与夜间辨识

- 二阶段所有地面小怪共用10只上限，约两波补员即可填满；每种小怪原有数量限制仍生效。补员、死亡分裂、畸变体孵化统一经过同一限制。
- 满员时在地形查找前就停止补员，不再为无法出生的小怪反复搜索地面。
- 小怪远离所有存活玩家1500像素、持续45帧后开始24帧淡出，无伤害、不分裂；有人仍在附近则保留。
- 六种地面小怪均有独立于环境照明的细轮廓，一阶段黄色、二阶段红色，转场跟随主题色渐变。轮廓由原贴图透明度生成并缓存，保持原动画帧与平滑攀爬旋转；不会把黑色甲壳漏掉，也不逐帧读取贴图。

## 最终死亡

死亡阶段由100帧延长为200帧。前120帧每6帧一组爆炸，之后每3帧一组；165帧后双点爆炸，180帧追加中央大爆炸。强度由1.5逐渐增加到2.8，中央爆炸3.4，搭配烟雾、短闪、冲击环与有间隔的爆炸音效。保留已有低特效选项。

死亡期间无敌并清理攻击，直到200帧才允许真实死亡与掉落；重复死亡判定不会重启演出时钟。
