# 执旗手

进阶：桃金娘 `MyrtleStandard` → 极境 `ElysiumStandard` → 嘉辛塔 `JacintStandard` → 琴柳 `SaileachStandard`。

四把均使用已有芬长枪作为临时物品/手持贴图，技能图标暂借红豆图标。没有旗布动画。

## 操作与支援

- 未攻击时竖直举枪，不跟随准星转动。左键锁定本次方向，54帧完成平滑转向、近距离前戳、收回与举起；只有中间戳刺段有伤害，枪尖有效长度96像素，前伸30像素。物品与弹幕均为召唤伤害，不占召唤栏位。
- 只在手持时为800像素内的自身与友方玩家提供光环；同队友方或双方均未开启PvP的玩家可以受益。多个执旗手光环取最高阶，不相加。
- 四阶光环依次提供5/7/9/11%移速、2/4/6/8防御、每秒1点生命恢复和3/5/7/9%召唤伤害。召唤伤害通过玩家伤害属性生效，既有仆从/哨兵依照tModLoader的持续伤害属性更新规则受益。
- 统一技能键开启选中技能，期间本人虚化免伤，停止自己的物品、弹幕、仆从及直接扣血型弹幕伤害，不删除仆从。移动与地形碰撞不变；切换物品、技能、死亡或失去使用物品能力时结束。
- 自己施加的普通NPC Buff在虚化期间暂停产生效果，剩余时间仍流逝，结束后恢复。对绕过Buff数组的持续伤害，仅在敌人的所有参战玩家均处于虚化时暂停其负生命恢复，避免直接抹除其他玩家的持续伤害。混合来源的自定义DoT没有统一的逐来源记账接口，仍需双客户端专项验收。
- 每个角色分别保留各把执旗手、各技能的剩余技力，切换不能重复领取初始技力；非手持状态不额外充能。死亡恢复初始资格。
- 玩家粒子参考灾厄 `Buffs/DamageOverTime/Shadowflame.cs` 的角色身体矩形发射方式，使用本模组独立颜色、运动和原版Dust，无灾厄资源或代码依赖。

## 费用与技能

费用接入现有 `DeploymentCost` 资源球：1费用补充当前手持公共技能1技力。服务端负责产出，技能期间不吸收；费用约10秒过期，早期产出的球可能在长技能结束前消失。可以给附近队友使用。

## 冲锋手费用审计

红豆、格拉尼、野鬃、风笛共同继承 `VanguardSpearWeapon`，原本已能通过公共接口吸收费用，但没有击杀产费。本次增加 `ChargerDeploymentCost`：手持冲锋手武器、作为最后参战玩家击杀敌人时，服务端在敌人处产出1点费用；排除友方、雕像生成单位、低生命实体和多节实体的附属节，避免按火花/追击/命中重复发放。

仓库没有“部署这把武器先扣费用”的机制，因此没有凭空增加原作的撤退返还部署费用。四把的戳刺、冲刺和技能配置保持原有实现，仅增加费用说明与共享击杀产费。

套装使用的 `OperatorDeployCostPlayer.DeployCost` 计数仍与可吸收费用球分离。本次未修改可露希尔、套装经济或其他职业。
