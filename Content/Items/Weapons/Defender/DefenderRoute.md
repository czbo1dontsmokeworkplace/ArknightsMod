# 重装武器路线

黑角 → 米格鲁 / 卡缇（二选一作为下一阶材料）

- 米格鲁或卡缇 → 蛇屠箱 → 可颂 → 年
- 米格鲁或卡缇 → 蛇屠箱 → 火神 → 泥岩
- 米格鲁或卡缇 → 坚雷 → 雷蛇
- 米格鲁或卡缇 → 火哨 → 号角
- 可颂 + 火神 → 森蚺
- 黑角 + 骨头 ×10 → 原版钴护盾（便利配方，不进入职业体系）

所有重装共用 `DefenderHoldout` 和 `ShieldHelper` 的卡缇/坚雷持握、步行、举盾模板。
闲置主武器按 Fran 的背负绘制方式收在身后：近战武器倾斜、两把要塞炮横放；盾牌保持固定姿势，不随走路或跑步摆动。攻击时主武器切回手持，结束后恢复背负。
普通挥砍与举盾互斥；只有要塞能边举盾边开火。森蚺的右键替换为撞击冲刺。
举盾统一为防御力 ×1.5、伤害减免 +0.5、免击退、移动速度 ×0.4。
保留公共正面招架的一次伤害减半、10秒冷却和5秒招架增益；背后受击不消耗招架。
号角旧的专属防御、伤害惩罚、双倍炮击反击与独立盾牌绘制入口不再使用。

| 分支 | 武器 | 攻击类型 / 特点 |
| --- | --- | --- |
| 铁卫 | 黑角、米格鲁、卡缇、蛇屠箱、可颂、年 | 近战；年一技能转为魔法伤害 |

| 不屈者 | 火神、泥岩 | 近战、自身恢复；同样遵守公共举盾禁攻 |
| 决战者 | 森蚺 | 近战；右键400%伤害冲刺，撞击反弹，冲刺阶段完全免伤，冷却90帧 |

年不再抛盾：锡灼强化近战法术斩击；铜印举盾固守并在受击时近身反震；铁御强化攻击和附近友方防御。
反震是技能被动，举盾仍不能进行主动挥砍或射击。
